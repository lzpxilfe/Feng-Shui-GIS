# 중국 데이터 가이드 (China Data Guide)

중국 자료로 이 플러그인을 돌릴 때 **결과를 조용히 무효화하는** 함정이 하나 있습니다.
좌표계 문제입니다.

## 1. GCJ-02 / BD-09 편의 좌표계

중국 웹 지도 서비스는 WGS84를 그대로 쓰지 않습니다.

| 좌표계 | 쓰는 곳 | WGS84 대비 |
| --- | --- | --- |
| **WGS84** | SRTM, ALOS, 대부분의 국제 위성자료 | 기준 |
| **GCJ-02** (国测局坐标, 화성좌표) | 高德(Amap), 腾讯, Google 중국 타일 | 약 100~700m |
| **BD-09** (百度坐标) | 百度地图 | GCJ-02 위에 추가 편이 |

**문제의 핵심은 이 좌표계들이 자기 정체를 밝히지 않는다는 것입니다.**
중국 지도에서 디지타이징한 레이어는 WGS84 레이어와 **똑같이 EPSG:4326이라고 보고합니다.**
파일 안에 구분할 단서가 없습니다.

30m DEM에서 500m 편이는 **약 17셀**입니다. 능선도, 수계도, 사신사 위요도도 전부
엉뚱한 지형에서 읽히지만, 경고는 하나도 뜨지 않습니다. 점수는 정상적으로 나옵니다.
그래서 위험합니다.

### 도시별 편이량과 권장 좌표계

| 위치 | 경도 | GCJ-02 편이 | BD-09 편이 | 권장 투영 좌표계 |
| --- | --- | --- | --- | --- |

## 2. 플러그인이 하는 일과 하지 않는 일

**합니다**
- 분석 범위가 중국 경내면 편이량(m)과 DEM 셀 환산값을 경고로 띄웁니다.
- 경위도 DEM을 거부할 때, "투영 좌표계를 쓰세요"가 아니라 **해당 범위에 맞는 구체적인
  가우스-크뤼거 3도대 EPSG 코드**를 알려줍니다.
- GCJ-02 / BD-09 / WGS84 상호 변환 함수를 제공합니다.

**하지 않습니다**
- **입력 자료가 어느 좌표계인지 자동 판별하지 않습니다.** 판별이 불가능하기 때문입니다.
  파일에 그 정보가 없습니다. 판단은 자료 출처를 아는 사용자만 할 수 있습니다.
- 자동으로 변환해서 조용히 고쳐놓지 않습니다. 잘못 짚으면 오히려 500m를 더
  어긋나게 만들기 때문입니다.

## 3. 좌표계 정하기

중국 국가표준은 대축척(1:10000 이상) 작업에 **3도대 가우스-크뤼거**를 씁니다.
지형 분석은 여기 해당합니다.

| 상황 | 권장 |
| --- | --- |
| 단일 유적·마을 (범위 3도 미만) | `CGCS2000 / 3-degree Gauss-Kruger CM {경도}E` (EPSG:4534~4554) |
| 성(省) 단위 (3~6도) | `CGCS2000 / Gauss-Kruger CM {경도}E` (EPSG:4502~4512) |
| 전국 단위 (6도 초과) | China Albers Equal Area (`+proj=aea +lat_1=25 +lat_2=47 +lon_0=105`) |

`EPSG:4490`(CGCS2000 지리좌표)은 **도(度) 단위라 그대로 쓰면 안 됩니다.**
플러그인이 거부합니다.

## 4. 변환하기

플러그인과 함께 설치되므로 QGIS 파이썬 콘솔에서 바로 쓸 수 있습니다.

```python
from feng_shui_gis.china_geodesy import transform, gcj02_offset_meters

# 高德 지도에서 딴 좌표를 WGS84로
lon, lat = transform(116.397516, 39.907618, "gcj02", "wgs84")

# 百度 지도에서 딴 좌표를 WGS84로
lon, lat = transform(116.403891, 39.913962, "bd09", "wgs84")

# 이 지점에서 좌표계를 잘못 짚으면 몇 m 어긋나는지
print(gcj02_offset_meters(116.3913, 39.9062))   # -> 약 556 m
```

레이어 전체를 변환하려면 각 피처 좌표에 같은 함수를 적용하면 됩니다.
변환 정밀도는 미터급이며, **측지 성과급 변환이 아닙니다.** 공개된 근사식입니다.

## 5. 자료 출처별 판단 기준

| 출처 | 좌표계 | 조치 |
| --- | --- | --- |
| SRTM, ALOS World 3D, ASTER GDEM | WGS84 | 그대로 사용 |
| 天地图 (国家地理信息公共服务平台) | CGCS2000 | 그대로 사용 (투영만) |
| 高德/腾讯 지도에서 디지타이징 | GCJ-02 | **변환 필요** |
| 百度 지도에서 디지타이징 | BD-09 | **변환 필요** |
| OpenStreetMap | WGS84 | 그대로 사용 |
| 출처 불명 | **알 수 없음** | 알려진 지점과 대조해 확인 |

출처가 불명확하면, 위성영상에서 명확히 식별되는 지점(다리 끝, 건물 모서리)을 하나
찍어 자료의 좌표와 비교해 보세요. 수백 미터 어긋나 있으면 GCJ-02 계열입니다.

## 6. 왜 자동 변환을 넣지 않았는가

자동 변환은 **좌표계를 확실히 알 때만** 안전합니다. 모르는 상태에서 변환하면
맞았을 자료를 500m 틀리게 만듭니다. 이 플러그인은 오차를 조용히 만드는 쪽보다
사용자에게 판단을 넘기는 쪽을 택했습니다.
