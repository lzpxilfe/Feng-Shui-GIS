# Visualization Language

This plugin should not draw Feng Shui outputs as thin abstract wiring diagrams.

The target visual language is:

- `ridge as spine / vein`
- `water as vessel / flow ribbon`
- `hyeol as a field center, not a pin`
- `left-right-front-back support as enclosure, not only connection lines`

## Phase 1: Embodied Linework

The first rendering upgrade uses multi-layer symbols:

- outer aura: broad, faint structural presence
- body band: the readable main body of the line
- inner core: a thin energetic centerline

This is now applied to:

- ridge hierarchy
- hydro hierarchy
- structural term links
- term points as halo/body/core markers
- hyeol fields as translucent held-basin polygons
- sashinsa and jangpung as translucent enclosure fields

## Why This Matters

Feng Shui is not only about discrete labels.
It depends on whether the viewer can see:

- thickness and thinning of a ridge
- gathering and release of water
- how a point is held, opened, or exposed
- whether the system feels skeletal, vascular, or fragmented

If the map only shows isolated points and uniform strokes, much of the logic disappears.

## Next Visual Steps

The next upgrades should continue moving from point-and-line emphasis toward dynamic field visualization:

1. `ridge thickness from hierarchy`
   vary ribbon width from rank, continuity, and relief
2. `hydro pulsation from accumulation`
   vary flow ribbon width from drainage support and confluence
3. `field blending and masks`
   soften overlaps between hyeol field, jangpung field, and sashinsa field

## Design Rule

Use diagrams only as a secondary layer.
The base map should feel like a living terrain body first, and an annotated model second.
