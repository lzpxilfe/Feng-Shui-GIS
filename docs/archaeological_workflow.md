# 역사고고학 연구 워크플로 (Archaeological Research Workflow)

## 0. 이 문서의 목적

이 플러그인을 **논문에 쓸 수 있는 형태로** 사용하는 절차를 정합니다.
"점수를 뽑는 법"이 아니라 **"뽑은 점수로 무엇을 주장할 수 있는가"** 가 핵심입니다.

## 1. 경쟁 지형: 왜 도구 개수로는 못 이기나

중국 상용 GIS(SuperMap·MapGIS·GeoScene)는 1200개 이상의 처리 도구, 3D, AI,
국가 공간정보 인프라, 정부 조달 채널을 갖고 있습니다. 여기서 이기려는 것은 무모합니다.

그런데 조사해 보면 **그 플랫폼들에 풍수 기능은 내장되어 있지 않습니다.**
풍수 연구는 범용 GIS 위에 매번 새로 얹힙니다. 연구자가 가중치를 손으로 정하고,
한 사례군에 적합성 중첩을 돌리고, 발표하고, 다음 연구자는 처음부터 다시 합니다.

즉 **선점한 풍수 GIS 제품은 없습니다.** 비어 있는 자리는 도구가 아니라
**재현 가능한 분석 단위**입니다. 이 플러그인이 노릴 자리는 그쪽입니다.

| 경쟁하지 않을 것 | 경쟁할 것 |
| --- | --- |
| 처리 도구 개수 | 개념–지표–근거의 명시적 연결 |
| 3D·렌더링 품질 | 사례 간 비교 가능한 산출 규격 |
| 대용량 래스터 속도 | 배경 대비 검증(귀무모형) |
| 엔터프라이즈 서버 | 데이터셋 카드와 유효범위 기록 |

## 2. 핵심 질문을 바꾼다

**나쁜 질문:** "이 절터의 풍수 점수는 몇 점인가?"
→ 0.72가 나와도 의미를 알 수 없습니다. 그 지역은 아무 데나 찍어도 0.68일 수 있습니다.

**좋은 질문:** "이 절터들은 같은 지형에서 무작위로 고른 자리보다 높은 점수를 받는가?"
→ 이건 답할 수 있고, 반증 가능하며, 다른 사례군과 비교할 수 있습니다.

이 차이가 **서술(description)과 주장(claim)** 을 가릅니다.

## 3. 절차

### 3.1 사례 정의를 먼저 고정한다

분석을 돌리기 전에 다음을 문서로 확정합니다. 나중에 바꾸면 결과가 오염됩니다.

- **연구 질문** — 무엇을 확인하려는가
- **대상군(positives)** — 어떤 유적, 몇 개, 위치 근거(문헌·지표조사·발굴)
- **시기 범위** — 조성 시점 기준인가 사용 시점 기준인가
- **관측 단위** — 개별 유구인가 유적군 중심인가
- **배경 정의** — 무작위 점을 **어디서** 뽑을 것인가 (아래 3.2)
- **DEM 출처와 해상도**
- **조사 편향** — 이 유적들은 왜 발견되었는가

`benchmarks/` 의 기존 케이스 문서가 이 형식입니다.

### 3.2 배경 표집 기준을 명시한다 — 가장 중요한 단계

귀무모형의 신뢰성은 전적으로 **배경을 어디서 뽑았는가**에 달려 있습니다.

| 배경 정의 | 이 배경으로 유의하면 말할 수 있는 것 |
| --- | --- |
| 래스터 전체 | 거의 없음. 절벽·수면과 비교하면 뭐든 유의합니다 |
| 육지 전체 | 약함. "물이 아닌 곳보다는 낫다" |
| 경사 25° 미만 육지 | 쓸 만함. "사람이 쓸 수 있는 땅 중에서 특별하다" |
| 동시기 일반 취락 분포 | 강함. "같은 시기 보통 자리보다 특별하다" |

**절벽과 비교해서 얻은 유의성은 아무것도 증명하지 않습니다.**
배경을 좁힐수록 주장은 강해지고, 통과하기는 어려워집니다. 그게 정상입니다.

`background_comparison()`은 `background_policy` 인자를 **필수**로 받습니다.
기준을 적지 않으면 계산 자체가 거부됩니다.

### 3.3 모델을 고정한 채 비교한다

캘리브레이션과 귀무모형은 **다른 작업**입니다. 섞으면 안 됩니다.

- **캘리브레이션** — 국지 표본에 가중치를 맞춥니다. *조정*입니다.
- **귀무모형** — 모델을 고정하고 배경과 비교합니다. *추론*입니다.

같은 자료로 가중치를 맞춘 뒤 그 자료로 유의성을 주장하면 순환논증입니다.
캘리브레이션을 썼다면, 검증은 **다른 지역**에서 해야 합니다.

### 3.4 실행

```python
from feng_shui_gis.null_model import background_comparison, comparison_summary

result = background_comparison(
    observed_scores,      # 대상 유적들의 fs_score
    background_scores,    # 3.2 기준으로 뽑은 무작위 점들의 fs_score
    background_policy="경사 25도 미만 육지, 수면 제외, n=1000",
    seed=42,
)
print(comparison_summary(result, "ko"))
```

### 3.5 결과를 읽는다

산출물은 세 가지입니다.

- **Cliff's delta** — 효과 크기. 관측 유적이 배경보다 높을 확률에서 낮을 확률을 뺀 값.
  정규성 가정이 없고 [-1, 1]로 유계라 사례 간 직접 비교가 됩니다.
- **순열검정 p값** — 라벨을 섞었을 때 이만한 차이가 우연히 나올 빈도.
- **평균 백분위** — 관측 유적이 배경 분포에서 평균 몇 번째인가.

**p값보다 delta를 먼저 보십시오.** 표본이 크면 무의미한 차이도 유의해집니다.
delta가 `negligible`이면 p가 작아도 할 말이 없습니다.

## 4. 무엇을 주장할 수 있고 없는가

`background_comparison()` 결과에 이 문장들이 함께 들어갑니다.

**주장할 수 있는 것**
> 관측된 유적들은 명시된 배경 기준으로 뽑은 위치들과 **이 모델이 다르게 점수 매기는**
> 지형에 있다.

**주장할 수 없는 것**
- 풍수가 입지의 **원인**이었다 — 상관은 인과가 아닙니다. 배산임수 지형은
  방어·용수·농경·일조 면에서도 유리합니다. 풍수는 여러 설명 중 하나입니다.
- 이 모델이 **풍수를 측정한다** — 모델은 지형 지표를 계산합니다. 그 지표가 풍수적
  판단과 얼마나 겹치는지는 별도로 검증해야 할 문제입니다.
- 조사되지 않은 곳에 **유적이 없다** — 알려진 유적은 사람이 찾아본 곳에 있습니다.
- 결과가 **다른 지역·시대에 적용된다** — 유효범위는 검증한 범위까지입니다.

## 5. 현대 DEM으로 과거 경관을 읽는 문제

이 도구의 가장 큰 구조적 한계입니다. 반드시 명시하십시오.

| 변형 | 영향 |
| --- | --- |
| 하천 직강화·제방 | 수계 위치와 형태가 조선 후기 이후 크게 바뀜 |
| 댐·저수지 | 없던 수면이 생기고 계곡이 잠김 |
| 간척 | 해안선 자체가 이동 |
| 도로·택지·절토 | 능선이 잘리고 지형이 평탄화됨 |
| 산림 변화 | 조망 분석에 영향 (다만 이 도구는 지형 차폐만 봄) |

**대응**
- 가능하면 구지형도(1910년대 지형도 등)와 대조해 변형 구간을 식별합니다.
- 변형이 심한 구간의 유적은 별도로 표시하고, 민감도 분석에서 빼고도 결론이
  유지되는지 확인합니다.
- 결론에 "현대 지형 기준"임을 명시합니다.

## 6. 한국 사례군 후보

재현 가능한 벤치마크를 쌓기 좋은 순서입니다.

| 사례군 | 표본 | 위치 근거 | 난이도 |
| --- | --- | --- | --- |
| **조선 읍치(邑治)** | 300여 곳 | 『신증동국여지승람』 등 문헌, 읍성·관아터 | 낮음 — 표본이 크고 위치가 명확 |
| 향교 | 300여 곳 | 현존 다수 | 낮음 |
| 조선 왕릉 | 40기 | 확정 | 낮음, 다만 표본이 작음 |
| 서원 | 수백 | 문헌·현존 | 중간 |
| 전통 마을 | 다수 | 지정 마을 위주라 편향 큼 | 중간 |
| 백제·신라 고분군 | 다수 | 발굴 자료 | 높음 — 조사 편향이 큼 |

**읍치가 첫 사례로 가장 적합합니다.** 표본이 300여 개로 통계적으로 충분하고,
위치가 문헌으로 특정되며, 풍수적 입지 선정이 적용된 것으로 연구된 사례군이고,
전국에 분포해 지역별 교차검증(한 도로 학습, 다른 도로 평가)이 가능합니다.

## 7. 중국 사례와의 비교 가능성

같은 분석 규격을 쓰면 한국 읍치와 중국 州縣 치소를 **같은 척도로** 비교할 수 있습니다.
이게 이 도구가 가질 수 있는 가장 독자적인 자리입니다. 범용 GIS는 규격을 제공하지
않기 때문에, 두 나라 연구를 비교하려면 지금은 논문을 손으로 읽는 수밖에 없습니다.

비교 시 반드시 함께 기록할 것:
- 용어 대응 등급 ([docs/chinese_terminology.md](chinese_terminology.md))
- 각 사례의 배경 표집 기준 — 다르면 delta를 직접 비교할 수 없습니다
- 지형 자체의 차이 (화북 평원과 한반도 산지는 배경 분포가 다릅니다)
