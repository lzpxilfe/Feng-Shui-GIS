# 사용자 사용성 검증 프로토콜 (Layer B)

Updated: 2026-04-04

목적: 첫 사용자(초보자)가 플러그인 설치 직후 **샘플 프로젝트로 5~10분 안에** 결과를 이해하고 재현할 수 있는지 검증합니다.

## 1) 준비

- `docs/first_run_guide.md`를 읽고 실행 환경 준비
- `examples/sample_project/README.md`에서 샘플 프로젝트 열기
- 아래 실패 시나리오를 별도 트랙으로 측정
  - bad CRS
  - no water layer
  - no site layer
  - cancel/rerun
  - language restore

## 2) 실사용 관측 항목

- 최초 실행까지 소요 시간(분)
- 사용자가 막힌 횟수(질문 수 기준)
- 사용자의 중단 지점(탭, 버튼, 메시지)
- 결과 지도/리포트에서 “무엇이 핵심인지”를 이해했는지(선택형)
- 재시도 없이 완료했는지 여부

## 3) 간단 체크리스트 (5~10분 기준)

1. README 링크에서 샘플 프로젝트를 연다.
2. DEM / water / sites를 확인한다.
3. analysis를 1회 실행한다.
4. 결과 레이어를 map으로 확인한다.
5. compare 또는 calibration을 선택 실행한다.
6. report/artifact를 확인한다.

성공 기준(1인 실험 기준)
- 위 6개가 위 순서로 완료되며, 10분 이내 종료
- 각 경고 메시지에서 “무슨 조치를 해야 하는지”가 바로 보임
- 최소 1회 run manifest와 report 파일이 생성됨
